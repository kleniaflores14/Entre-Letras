# Entre Letras

Sitio web responsive de recomendaciones literarias para jóvenes universitarios.

## Archivos
- `index.html` — estructura y contenido.
- `styles.css` — diseño, responsive y modo oscuro.
- `script.js` — catálogo, filtros, búsqueda, galería, modal y persistencia del tema.

## Cómo abrirlo
Abre `index.html` en un navegador moderno. No requiere servidor para funcionar.

## Funcionalidades
- Navegación por secciones.
- Búsqueda global y búsqueda del catálogo.
- Filtro por género.
- Botones de "Ver más información" con modal.
- Selección especial de libros para octubre.
- Galería con visor y navegación.
- Modo claro/oscuro guardado con `localStorage`.
- Menú móvil responsive.
- Imágenes de portadas, autores y ambiente literario.
